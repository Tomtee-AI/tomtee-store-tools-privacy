# Privacy Policy: Tomtee Store Tools

_Last updated: October 19, 2026_

Tomtee Store Tools is a private application operated by Tomtee LLC, a Missouri limited liability company. It is used only by Tomtee LLC to manage its own eBay seller account.

## What the application accesses
When the account owner grants consent through eBay's sign-in, the application uses official eBay APIs to read and manage the owner's own seller data: listings, orders, offers, promotions, fees, and payouts.

## How data is used
Data is used only to price and manage the owner's listings and to produce internal sales and profit reports. Buyer information contained in orders is used only as needed to fulfill those orders and is not used for marketing.

## Sharing
Tomtee LLC does not sell, rent, or share any eBay user data with third parties.

## Storage and security
Data is stored only on systems controlled by Tomtee LLC and kept no longer than needed for bookkeeping. Access tokens are kept private and can be revoked at any time from the eBay account's settings.

## Account deletion
Tomtee LLC honors eBay marketplace account deletion requests and deletes any related data it holds.
